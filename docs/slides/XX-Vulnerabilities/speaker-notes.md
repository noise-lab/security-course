# Bonus — Speaker Notes (Vulnerability Discovery and Disclosure)

Per-slide context + clickable links. Bonus deck (off-schedule). In-deck notes (`::: {.notes}`) are visible via reveal.js speaker view (press **S**). Terse — enough for a future instructor to pick up.

| Slide | Context + Links |
|---|---|
| **Why Vulnerabilities Are Inevitable** | Frame: this lecture is about the ecosystem and law around finding-and-telling, not the mechanics of finding bugs. Include *privacy* vulnerabilities (data leaks), not just memory-corruption bugs. |
| **Today's Questions** | Roadmap. Legal material is the spine because it makes this a *policy* topic. Tie forward to the [CFAA debate `../../debates/cfaa.md`](../../debates/cfaa.md) and the [backdoors debate `../../debates/backdoors.md`](../../debates/backdoors.md). |
| **Privacy Vulnerabilities Are Real Vulnerabilities** | Nest thermostat leaking ZIP codes: [Acar, Huang, Li, Narayanan, Feamster, "Web-based Attacks to Discover and Control IoT Devices" (ACM SIGCOMM IoT S&P Workshop, 2018)](https://dl.acm.org/doi/10.1145/3229565.3229568). A "leak" with no memory-corruption bug is still a vulnerability with real-world consequences. |
| **Three Paths After You Find a Bug** | **Full / coordinated / no disclosure.** "Coordinated disclosure" has largely replaced "responsible disclosure" (the older term put moral weight on the researcher). De facto deadline norm is 90 days ([Google Project Zero disclosure policy](https://googleprojectzero.blogspot.com/p/vulnerability-disclosure-policy.html)). Push on the hardware-bug case where a "patch" may be impossible. |
| **Zero-Days: When Nobody Has a Patch** | Grey-market economics: brokers and governments outbid legitimate vendors. Anchor: [Zerodium price list](https://zerodium.com/program.html) — top-tier iOS/Android RCE reaches seven figures. Bounty tables later make the incentive gap concrete. |
| **A 2026 Vignette: Disclosure Goes to War** | **Verify before class — dates and outcomes may have moved.** The "Chaotic Eclipse" episode (May 2026) is a modern restatement of the Felten/SDMI conflict. Coverage: search [The Hacker News](https://thehackernews.com/) and [The Record by Recorded Future](https://therecord.media/) for "Chaotic Eclipse" and the associated CVEs (*BlueHammer* CVE-2026-33825, *RedSun*, *UnDefend*). Ask: who was right? What would have changed the researcher's calculus? (Usually: a working bounty + a responsive vendor.) |
| **The DMCA and Anticircumvention** | [17 U.S.C. §1201](https://www.law.cornell.edu/uscode/text/17/1201). Decoupled from actual infringement — studying a DRM scheme to see if it's secure can itself be "the device." Every three years the Librarian of Congress grants [DMCA §1201 exemptions](https://www.copyright.gov/1201/) — security research has been a recurring (renewed) exemption since 2015. |
| **When Research Became a Crime** | **Sklyarov v. Adobe (2001):** [EFF case page](https://www.eff.org/cases/us-v-elcomsoft-sklyarov); the FBI arrest at DEF CON is the visual. **Felten v. RIAA (2001):** [EFF case page](https://www.eff.org/cases/felten-v-riaa); RIAA called Felten's *paper* a "circumvention device." |
| **Felten v. RIAA: The Timeline** | Threat alone achieved suppression for months — that's the chilling effect in action, no conviction required. |
| **The Computer Fraud and Abuse Act** | [18 U.S.C. §1030](https://www.law.cornell.edu/uscode/text/18/1030). The "exceeds authorized access" phrasing has been the battleground for 30+ years. Cross-link: [CFAA debate `../../debates/cfaa.md`](../../debates/cfaa.md). |
| **Does a ToS Violation Make You a Criminal?** | **Lori Drew (2009):** [*United States v. Drew*, opinion](https://cyber.harvard.edu/publications/2009/UnitedStatesvDrew). **Facebook v. Power Ventures (2016):** [Ninth Circuit opinion](https://law.justia.com/cases/federal/appellate-courts/ca9/13-17102/13-17102-2016-07-12.html). **hiQ v. LinkedIn (2019):** [Ninth Circuit opinion](https://cdn.ca9.uscourts.gov/datastore/opinions/2019/09/09/17-16783.pdf) — scraping public data does not violate CFAA. Line: code-based access controls vs. mere contract/policy restrictions. |
| ***Van Buren* and *Sandvig*: Protecting Researchers** | ***Van Buren v. United States* (2021):** [SCOTUS opinion](https://www.supremecourt.gov/opinions/20pdf/19-783_k53l.pdf); [EFF analysis](https://www.eff.org/deeplinks/2021/06/van-buren-victory-against-overbroad-interpretations-cfaa-protects-security). ***Sandvig v. Barr* (2020):** [Columbia Global Freedom of Expression case page](https://globalfreedomofexpression.columbia.edu/cases/sandvig-v-barr/) — researchers auditing sites for racial discrimination via ToS violation aren't criminals. The "code-based vs. contract" line remains open (Orin Kerr's framing). |
| **Bug Bounties: Would You Hire a Hacker?** | The "arsonist as Fire Marshal" line always lands. Bug bounties are partly a way to capture adversarial skill without the employment risk. |
| **What a Bounty Pays** | [Google Vulnerability Reward Program](https://bughunters.google.com/about/rules/6625378258649088/google-and-alphabet-vulnerability-reward-program-vrp-rules); [Microsoft bounty programs](https://www.microsoft.com/en-us/msrc/bounty); [Apple Security Bounty](https://security.apple.com/bounty/). Tiered by impact and exploit quality. Top-tier RCE reaches six figures on Google, seven on Apple/Zerodium. |
| **Bug Bounties Don't Erase the Tension** | Bounty "safe harbor" is a contract, not a law — only as strong as the company's promise and the prevailing CFAA reading. Chaotic Eclipse is the failure mode. |
| **Penetration Testing and Audits** | Pentest (find-and-prove-exploitable) ≠ full audit. Clean pentest report is not a clean bill of health — absence of found bugs ≠ absence of bugs. |
| **What a Pentest Report Looks Like** | [Cure53 Mozilla VPN report (2021)](https://research.mozilla.org/files/2021/01/Mozilla-VPN-Security-Audit-2021.pdf) is a good artifact — itemized issues (Low/Medium/Info), each actionable. Contrast with the Chaotic Eclipse dump: same technical content, opposite relationship to the vendor. |
| **Discussion: Is Penetration Testing Useful?** | Drive the limits home: black-box testing is bounded by time, scope, and the tester's imagination. Useful, necessary, never sufficient. |
| **Takeaways** | Connect 2001 (Felten) to 2026 (Chaotic Eclipse): same conflict, better law, still-broken incentives. Cross-link: [CFAA debate `../../debates/cfaa.md`](../../debates/cfaa.md) and [backdoors debate `../../debates/backdoors.md`](../../debates/backdoors.md). |
