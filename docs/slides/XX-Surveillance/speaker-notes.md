# Bonus — Speaker Notes (Data Collection and Surveillance)

Per-slide context + clickable links. Bonus deck (off-schedule). In-deck notes (`::: {.notes}`) are visible via reveal.js speaker view (press **S**). Terse — enough for a future instructor to pick up.

| Slide | Context + Links |
|---|---|
| **"It's Just Metadata"** | The Obama quote is from his [June 7, 2013 press conference](https://obamawhitehouse.archives.gov/the-press-office/2013/06/07/statement-president) defending the NSA bulk phone program after the initial Snowden disclosures. The whole lecture is a rebuttal: metadata is often *more* revealing than content because it is structured and machine-analyzable at scale. |
| **Today** | Roadmap: define metadata → show law treats it as low-sensitivity → show empirically that it isn't → bring to the present (Section 702, ISP/DNS surveillance, encryption-backdoor debates). |
| **Many Definitions, One Word** | Colloquial / engineering / legal definitions all roughly = "non-content." Legal matters most because it determines protection. Anchor: [*Smith v. Maryland*, 442 U.S. 735 (1979)](https://supreme.justia.com/cases/federal/us/442/735/) — the third-party doctrine originating from pen-register data. |
| **Metadata for a Phone Call** | Envelope metaphor. Parties, time, length, direction — everything *around* the words. |
| **The Envelope Analogy** | Wrigley Field (1060 W. Addison) is a UChicago in-joke. Point: the envelope alone reconstructs your social graph, schedule, locations. Metadata scales because it's structured. |
| **When the Definition Breaks Down** | The `searchengine.com/search?query=...` example is the killer: the URL is the content of your thought. Courts and statutes drew the line in a telephone world. Anchor: [Kerr, "The Fourth Amendment and New Technologies" (Michigan L. Rev. 2004)](https://repository.law.umich.edu/mlr/vol102/iss5/1/) on why the doctrine transfers poorly. |
| **Implicit Location: IP Addresses Are Maps** | Nobody thinks of an IP address as location data, but MaxMind / commercial geolocation maps it to a building. Redaction is a wink. |
| **The NSA's Bulk Metadata Programs** | **Bulk phone (2001–2015)** under [PATRIOT Act §215](https://www.congress.gov/bill/107th-congress/house-bill/3162) / FISA business-records orders. **Bulk email (2001–2011)** under FISA pen-register/trap-and-trace authority. Snowden disclosure timeline: [Guardian's "The NSA Files"](https://www.theguardian.com/us-news/the-nsa-files). |
| **How a Query Worked — and the USA FREEDOM Reform** | [USA FREEDOM Act (2015)](https://www.congress.gov/bill/114th-congress/house-bill/2048): ended bulk collection, data stays at telcos, government queries with specific selectors. Two-hop expansion still swept ~25k subscribers/query even after popular-number filtering. |
| **The Graph Has Hubs** | Anchor: [Mayer, Mutchler, Mitchell, "Evaluating the privacy properties of telephone metadata" (PNAS 2016)](https://www.pnas.org/doi/10.1073/pnas.1508081113) — the MetaPhone study. Call graph is heavy-tailed; two hops from a hub explodes the query set. |
| **Re-Identification Is Easy** | MetaPhone participants believed sharing numbers was safe. Researchers re-identified individuals via public directories + Google Places + Yelp. Classic anonymization-fails result. |
| **Inferring Sensitive Traits** | From metadata alone: home location, relationships (validated against Facebook friends), religion, health/firearms/finances via single revealing calls. Content was never needed. |
| **"It's Just Metadata" — Revisited** | Land the thesis. Bring it back to the Obama quote. Metadata is exactly what surveillance systems are built to exploit. |
| **A Live 2026 Fight: Section 702** | **Verify before class — this is fast-moving.** [Section 702 of FISA](https://www.law.cornell.edu/uscode/text/50/1881a); [Brennan Center Section 702 resource page](https://www.brennancenter.org/issues/protect-liberty-security/foreign-intelligence-surveillance-act-fisa); [Reforming Intelligence and Securing America Act (RISAA, 2024)](https://www.congress.gov/bill/118th-congress/house-bill/7888) reauthorized 702 for two years; the sunset/extension fight and the U.S.-person query warrant issue remained unresolved as of the last refresh. **Update this slide against the current status** — search "Section 702 reauthorization 2026" before class. |
| **Incidental Collection: The Core Tension** | The "backdoor search" loophole: agencies query 702 data for U.S. persons without a warrant. **Data-broker loophole**: agencies buy location data they couldn't subpoena. Anchor: [FTC action against Kochava (2024)](https://www.ftc.gov/legal-library/browse/cases-proceedings/2023170-kochava-inc). |
| **Can Your ISP Still See Your Traffic?** | Swire's 2016 whitepaper (funded by Broadband for America): [Working Paper on Privacy and ISP visibility](https://ftp.cs.princeton.edu/~feamster/research/papers/isp-privacy-comment-2016.pdf) triggered the FCC broadband privacy rulemaking debate. |
| **The Rebuttal: Metadata Leaks Anyway** | Feamster's rebuttal letter to the FCC (2016). Even with HTTPS, mobility, VPNs: **DNS lookups** (set by DHCP), **TLS SNI** (clear text), **IoT** (often unencrypted). Fraction on HTTPS isn't the point — the unencrypted long tail is. |
| **Closing the Leaks — and the New Trade-offs** | **DoH**: [RFC 8484](https://www.rfc-editor.org/rfc/rfc8484). **ECH**: [Cloudflare on Encrypted Client Hello](https://blog.cloudflare.com/announcing-encrypted-client-hello/); [ECH draft RFC](https://datatracker.ietf.org/doc/draft-ietf-tls-esni/). **ODoH**: [Cloudflare on Oblivious DoH](https://blog.cloudflare.com/oblivious-dns/); [Kinnear et al., RFC 9230](https://www.rfc-editor.org/rfc/rfc9230). Every fix relocates trust: ISP no longer sees queries, but a giant resolver now sees all of them. Ask *who can see what now?* rather than *is it encrypted?* |
| **The Other Side: ISP Data Has Legitimate Uses** | Steelman: DNS + traffic data underpin real public-interest security research. Drafting exception language narrow enough to prevent abuse but broad enough to permit real research is genuinely hard. |
| **Encryption Backdoors: The Current Front** | **Verify before class.** **UK TCN → Apple pulled Advanced Data Protection for UK users**, February 2025: [Apple statement / press coverage](https://www.bbc.com/news/articles/cgj54eq4vejo). Coverage: [Reuters](https://www.reuters.com/technology/uk-orders-apple-let-it-spy-users-encrypted-accounts-washington-post-reports-2025-02-07/). **EU "Chat Control" client-side scanning**: [EDRi tracker](https://edri.org/our-work/eu-chat-control-timeline/); mandatory-scanning version withdrawn by Danish Council presidency in late 2025 — verify current status. Core CS point: a backdoor is an intentional vulnerability; there is no math that opens only for "authorized" parties. |
