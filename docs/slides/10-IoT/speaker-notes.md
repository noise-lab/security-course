What the MediaError Says** (10–12) | • Chrome and Firefox return different strings for "exists" vs "404"; that difference is the new side channel.<br><br>• Safari times the fetches out, Edge returns no message: Attack 1 fails there.<br><br>• **What to say:** cross-origin responses are supposed to be opaque except images, CSS, and passive resources; Chrome paid a bounty. |

| 14 | **Attack Steps: Rebinding, Steps 1–2** (16–18) | • First answer is 6.6.6.6 with TTL 1; page loads and then requests a second resource, *test*. |
