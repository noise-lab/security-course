## Agenda

Per-meeting class notes, one file per term. The current term is listed first.

* [Autumn 2026 (Chicago)](agenda/2026-autumn.md)
* [Summer 2026 (Zoom, high-school session)](agenda/2026-summer.md)
* [Autumn 2025 (Chicago)](agenda/2025-autumn.md)

Each term's file records what was actually covered in each meeting, built from the class recording afterward. There is more material in the slides than any one term gets through, and exams only cover what appears here. The exam prompts in the repository use these files as input, so you can generate your own practice exams from them.
